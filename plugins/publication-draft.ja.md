## プライバシーポリシー案

### 運営者と対象

### 取り扱う情報と利用目的

| 情報 | 利用目的 |
| --- | --- |
| メールアドレス、表示名、任意の部署・役職・アバター、所属・権限 | アカウントの識別、ログイン、組織・プロジェクトへのアクセス管理、担当者・投稿者の表示、利用案内 |
| ハッシュ化パスワード、ログインセッション、認証Cookie | 本人の認証、セッション管理、不正利用の防止 |
| 要件、テスト設計、タスク、日程、文書、添付、コメント、関連・変更履歴、下書き | 利用者が指定した業務情報の保存・共有・編集・レビュー・復元 |
| MCPの接続先client、許可した組織・プロジェクト・scope、接続・失効日時、資格情報のハッシュ、操作の再送結果 | 本人が許可した範囲でのCodex操作、権限・期限の検証、取消、重複書込みの防止 |
| 操作者・対象・操作種別・日時、接続元IP、User-Agent、リクエスト情報などのログ | 重要操作の監査、障害調査、不正アクセス対策 |

通常の認証Cookieはブラウザからの認証とCSRF対策に使います。
通常アカウントでは、入力復元用の下書きをブラウザのlocalStorageとサーバーへ保存する機能があります。
共有端末では、利用後に保存された入力情報が残ることに注意してください。
広告・アクセス解析など追加の利用目的の有無は `[要確定]` です。

### 組織内での共有と外部サービス

業務情報は、Syncnesto上で権限を持つ同じ組織・プロジェクトの利用者が閲覧・操作できます。
組織の管理者は、その組織の重要操作の監査記録を閲覧できます。
運営上必要な権限を持つ運営者が保守・障害対応等で取り扱う範囲は `[要確定]` です。

公開環境は、アプリの配信・API実行にVercel、データベースにNeon、ファイル保存にSupabaseを使用します。
メール配送の委託先と、各委託先の処理地域・保持期間は公開前に確認します。
個人データの委託・第三者への提供・国外での取扱いに関する正式な説明は、その確認結果を反映します。

Codex連携は任意です。連携時に本人がプロジェクトを選び、その時点の本人権限の範囲で操作します。
Codexから要求した業務情報や操作結果はOpenAIのサービスへ渡り、会話や処理に使われます。
担当者候補、投稿者、本文などに含まれる個人情報も、対象操作の応答に含まれる場合があります。
OpenAI側の保存・利用は利用中のサービスの契約と設定に従います。
SyncnestoからOpenAI側の会話・保存情報を削除することはできません。

### 保存期間と削除

次の表は現行実装の挙動です。未確定の運用を解消してから公開文面へ反映します。

| 対象 | 現行の挙動 |
| --- | --- |
| 通常の業務情報 | ログアウトで消えない。対象資源をごみ箱へ移した場合、標準30日で復元できなくなる。実削除は対象組織に有効化した回収処理で行い、件数制限・失敗・再試行により後になる場合がある。 |
| 履歴・添付等 | 親資源の回収時に所有する履歴等も回収する。対象外の資源、監査ログ、バックアップを一律に同時削除するものではない。 |
| デモの業務情報 | 通常データと別のDB・Storageを使用する。ログアウト・リセット・期限切れ後にアクセスを無効化し回収する。回収失敗分は後続処理で再試行する。 |
| 通常の入力下書き | 標準30日で利用期限が切れる。ブラウザ側はその下書きを次に読み込む時に期限切れを除去する。サーバー上の実削除運用は要確定。 |
| MCP接続・資格情報 | accessは10分、接続・refreshは最大30日で失効する。解除後も接続記録は即時削除されない。期限切れの要求・資格情報・再送結果を定期的に実削除する処理は現時点でない。 |
| 認証セッション・監査・クラウドログ・バックアップ | 認証の失効と記録の実削除は異なる。監査回収CLIの既定は1095日で、自動削除の保証ではない。実際の保持・削除期間は要確定。 |

Codex連携はアカウントの「外部サービス連携」から解除できます。
解除は今後のMCPアクセスを止めます。既に作成した要件・テスト設計・タスク・コメントや、
OpenAI側に渡った情報の削除は別の操作です。
個人情報の確認・訂正・利用停止・削除などの相談は `syncnesto@gmail.com` で受け付けます。
本人確認の方法、組織内共有情報・監査記録の扱い、回答手順は公開前に確定します。

## 利用規約案

1. **提供者と目的**: `shime-hei` が提供するSyncnestoは、要件定義、テスト設計、タスク、文書等を扱うサービスです。公開環境の試用範囲とアカウント発行条件は `[要確定]` とします。
2. **アカウント**: 自分に発行されたアカウントを使用し、認証情報を他者と共有しないでください。所属・権限に応じて利用できる範囲が異なります。
3. **登録する情報**: 保存・共有する権利がある情報を登録してください。公開環境へ認証秘密、決済情報、医療情報、公的識別番号その他の機微な情報を入力しない条件を提案します。実業務・機密情報の利用条件は運営者が確定します。
4. **禁止事項**: 不正アクセス、他者へのなりすまし、権限の迂回、他組織の情報の取得、過剰な負荷、第三者の権利侵害、違法行為を禁止する案とします。
5. **Codex連携**: 連携は任意で、本人が許可したプロジェクトと現在の本人権限で動作します。閲覧専用・テスト実行専用・デモでは使えません。AIによる提案・作成・コメントの内容と変更範囲を確認してください。日程の一括変更は提示された案を確認してから適用します。
6. **保存と取消**: 通常の書込みはログアウトやCodex連携解除で取り消されません。削除・復元・保存期間はプライバシーポリシーの対象別の説明に従います。デモは終了後に保存を継続できません。
7. **入力内容の権利**: 登録内容の権利を運営者へ移すことを要求しない案とします。保存・表示・共有・指定された連携処理に必要な範囲で取り扱います。
8. **外部サービス**: Codexを利用する場合はOpenAIの契約・設定も適用されます。外部サービスの障害・仕様変更・利用制限により連携が使えない場合があります。
9. **変更・停止と責任**: 無料枠の上限、保守、安全対策、外部障害などで提供を制限する場合があります。稼働率・無期限保存・AI出力の正確性を保証する約束は設けない案です。サービス終了時の案内とデータ取出し、損害等の責任範囲は `[要確定]` とします。
10. **問い合わせ・改定等**: `syncnesto@gmail.com` を連絡先とします。施行日、規約改定の通知・同意手順、準拠法と紛争対応は `[要確定]` とします。
